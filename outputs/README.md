# Generated Outputs

This directory stores CSV, JSON, chart, audit, evidence, dashboard,
and machine-learning preparation artifacts generated by the project scripts.

Generated artifacts are intentionally excluded from version control because
they can be reproduced from the synthetic source data and the documented
execution commands.

The directory may contain:

- risk assessments;
- professional alerts;
- investigation queues;
- case-management records;
- audit trails;
- evidence metadata;
- operational dashboards;
- closure and reopening records;
- investigation feedback;
- clean training datasets;
- analytical reports and charts.

All demonstration data used by this project is synthetic and does not
represent real people, customers, organizations, or fraud investigations.
